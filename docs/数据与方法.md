# 数据与方法

> 这份文档**不在站点上发布**，只作为项目内部说明供你阅读。
> 站点对外只呈现结论与出处（页脚有署名），方法与取舍放在这里。

这个项目的设计目标只有一句话：**上线之后不需要任何人管理它。**

新模型发布、旧模型退役、价格调整、榜单更新，都会自动反映到页面上；
上游挂掉、改字段、限流，网站也不会坏——最坏的情况是这一版不更新，页面继续显示上一次的好数据。

---

## 一、三个上游，各自的职责

全部是公开、可再生、可再分发的数据。刻意没有接入任何禁止再分发或禁止自动抓取的数据源。

| 用途 | 来源 | 许可 | 取到的字段 |
| --- | --- | --- | --- |
| 综合智力与逐榜成绩 | [Epoch AI](https://epoch.ai) | CC-BY 4.0 | ECI 综合智力指数及其置信区间、59 个细分榜单的模型级成绩、训练算力、权重开放状态 |
| 模型规格、定价与渠道 | [models.dev](https://models.dev) | MIT | 上下文与输出上限、输入/输出/缓存价格、模态、工具调用与结构化输出支持、发布日期、知识截止，以及**同一款模型在 170 多个渠道的报价** |
| 分维度能力成绩 | [LiveBench](https://livebench.ai) | Apache-2.0 | 逐任务原始得分，按官方 categories 定义归成 7 个能力大类 |

还有一块是**人工策展**的、不属于自动化范围：`src/content/papers.ts` 里的论文与发布文章。
每条都带一个 `unlocks` 字段，写明「这款模型因此新增了什么能力」。
其中 arXiv 编号全部用 `export.arxiv.org` 的 API 核对过标题，官方链接只收录实测返回 200 的——
核不过的一律不收，宁可少一条，也不放一个可能 404 的链接进去。

## 二、零维护是怎么做到的

整条链路没有任何需要人工介入的环节。唯一需要人类常识的地方，是一张某家厂商的形象母题查表。

### ① 每天一次自动同步

GitHub Actions 每天 UTC 20:10（北京 04:10）把三个上游抓下来、归一化、按「厂商 + 规范名」合并成一份快照，
校验通过后提交回仓库。

条件请求带 ETag：上游没变就返回 304，零流量、零解析。同步和画形象两步都是 `continue-on-error`，
失败只开 issue 留痕，**不阻断发布**——已经生成好的静态页面继续服务上一版好数据。

### ② 合理性闸门

上游改字段是**静默的**。真实的失效模式不是报错，而是「解析器一条都没接到，覆盖率从 38% 掉到 0%，
页面照常渲染，只是所有排名都错了」。

所以闸门查的不是异常，是**形状**：

- 模型总数骤降超过 25%
- ECI 覆盖率相对腰斩
- 官方价格整批消失
- 出现负数价格
- 出现重复 slug

任一条命中就**拒绝写入、保留旧快照**，并以非零退出码结束，同时开一条 issue 留痕。

这条闸门真的拦下过东西：厂商归属规则收紧那次，模型数从 855 掉到 421，
核对确认是合法变更（云平台托管别家模型被正确降级为报价）之后，才重置基线放行。

### ③ 文案为什么不会胡说

页面上所有文字都是「取数 → 排序 → 套模板」出来的，**不调用任何大模型**，
也不展示上游返回的任何自由文本。

好处有两个：模型信息永远不会被编造；同一份数据渲染两次就能同时出中英文，新模型进来自动两边到位。

### ④ 形象也是生成的

全站 Q 版形象由厂商母题（鲸、月牙、灯笼、棱镜……）确定性合成，同一份数据永远产出同一张图。
加一家厂商只需要在母题表里加一行，不需要有人画图——这是「零维护」在美术素材上的落地。

## 三、几条刻意的取舍

这些决定看起来像限制，其实是这个站能长期不腐坏的原因。

### 分位，而不是绝对阈值

全站所有「强 / 弱 / 便宜 / 记性好」都是**在当前全体模型里的分位**。

写死的阈值会被时间腐蚀——两年前「上下文 128K」值得写进标题，今天是入门配置。
用分位，就没有人会因为「指标过期」而被迫回来改文案。

### 跨赛制的分数不相遇

编程这个维度被切成了十几个互不兼容的赛制（SWE-bench Verified / Pro、Terminal-Bench、
Aider Polyglot……），同一个模型换套脚手架能差二三十分。

所以每个榜只在自己的参赛人群里算分位，**结构上就不可能被混算成一个数**。

### 拿不到就写「暂无」

空值一律显示为「暂无数据」，并且明确写出「暂无不等于弱」。

没有任何一个数字是估算、外推或补全出来的——宁可页面上缺一块，
也不放一个看起来合理但无法回溯的数字。

### 价格的免责边界

价格是各平台自己提交的挂牌价，不含优惠与合约折扣，也不代表实际账单。

本站只做归集、换算与跳转，**不参与交易、不收取佣金、不代理任何一家**。下单前请以渠道页面为准。

## 四、三个「不做就等着出错」的具体陷阱

### 1. 零价不等于免费

上游有 240 多条报价的单价是 `0`，但它们**不是不花钱**，而是**不按 token 计价**：
阿里云百炼的 token 套餐、腾讯/智谱/MiniMax 的 coding plan、NVIDIA NIM 与 HuggingFace 的试用额度。

直接渲染成「$0」会同时错两次：读者以为模型白送，而任何「谁更便宜」的排序都会让一个
「$20/月不限量」的套餐以「$0/M」的身份排到所有真实按量价格前面。

处理方式是**保留但降级呈现**——它确实是真实存在的购买途径，用户就是想知道有没有包月的路子。
排序时排除，展示时标成「套餐/免费」。`scripts/verify.ts` 里有一条构建期检查专门守这个语义。

### 2. 低到不像真的价格，不当优惠宣传

约 2900 条第三方报价里，绝大多数**高于**官方价（转售要加价），这合理。
但有十几条只有官方价的 4%~19%，且高度集中在两家渠道、跨十几个不同模型都是同一个比例。

这种一致性说明它大概不是折扣，而是**计价口径不同**（共享号池、按字符计费、套餐折算）。

站点没法验证第三方的账单，所以既不删也不当优惠：单独标「存疑」，并且**不计入「最大价差」统计**，
也不参与「性价比」榜——否则 GPT-5.5 会凭空变成全站性价比第一。

### 3. 归一化里最隐蔽的一个坑

三个上游对同一款模型的写法完全不同，直接按名字对齐会得到一堆重复和错配。

版本号粘连要处理：`gpt-5-2` → `gpt-5.2`。但这里有个陷阱——`llama-3-70b` 同样满足「数字-数字」，
会被粘成 `llama-3.70b`，显示出来就是「Llama 3.70b」，把「第 3 代 70B 参数」读成了「3.70 这个版本」。

必须让正则检查后面的单位字母（`b/m/k/t`）来区分。同类问题一次影响过 16 款模型。

另外还有：日期戳要剥（`Deepseek V4 Pro 0813` 会在四家厂商名下各出现一次）、
云平台托管别家模型要降级为报价（否则 Amazon Bedrock 下的 Claude 和 Llama 会被算成「亚马逊发布的模型」）、
放宽匹配必须**只在唯一命中时才认**（上游经常一边写 `claude-opus-4.6`、另一边写 `claude-opus-4-6-latest`）。

## 五、本地复现

两条链路都是离线确定性的：不需要任何 API 密钥，同样的输入永远产出同样的输出。

```bash
npm run pipeline   # 抓数据 → 画形象 → 渲染 → 体检
npm run serve      # http://127.0.0.1:3100
```

同步管线不依赖任何第三方库：Epoch 的 zip 解析、CSV 解析、HTTP 条件请求都是自己写的。
Web 端也是零依赖的静态生成——页面在构建期就已经完整确定，运行时不需要后端，也不需要任何密钥。

---

## 六、本地复现的最低要求

```bash
node --version          # 需要 >= 22.18（用到 --experimental-strip-types 与全局 WebSocket）
```

只需抓过一次数据之后，改样式或文案时可以只跑 `build` + `verify`，不必联网。

## 七、许可与署名

代码以 MIT 发布。三份上游数据各自遵循其原始许可：

- Epoch AI —— CC-BY 4.0（需署名）
- models.dev —— MIT
- LiveBench —— Apache-2.0

本站的署名体现在页脚与每一处结论的出处标注上。

站内的 Q 版形象由本站脚本合成，不使用任何第三方美术素材，因此没有额外的素材署名义务。
如果你想给某个模型换成官方形象，往外链覆盖表 `src/content/avatar-overrides.ts` 里加一行地址即可，
仓库存的是地址而不是图片本体。

## 八、已知边界

- **ECI 覆盖率约一半**。Epoch 只测一部分模型，未覆盖的模型在相关榜单上不参与，
  页面会显示「暂无综合评分」而不是编一个数出来。
- **LiveBench 匹配率偏低**。它的模型命名与 models.dev 差异最大，且榜单本身只收录约 58 款。
- **GitHub / HuggingFace 链接未收录**：本机抓取时这两个域名经代理不可达，无法实测 200，
  因此官方链接只收了能验证的那些。
- **报价是挂牌价**，不含优惠、批量和合约折扣，也不代表实际账单。
- 本站只做归集与换算，不参与任何交易、不收取佣金。
